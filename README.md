# VitalGrid — Power Outage Vulnerability Index

Power outages are climate events. For residents dependent on 
powered medical equipment — ventilators, oxygen concentrators, 
powered wheelchairs — they're potentially fatal.

VitalGrid maps where outage risk meets medical device dependency 
across Philadelphia neighborhoods, so planners act before the 
lights go out.

**Live tool:** https://meyeringn.github.io/vitalgrid

## What It Does
- Composite Power Vulnerability Score for 36 Philadelphia neighborhoods
- Five tabs: Neighborhood Map, Equity Analysis, Compare, Policy Actions, Medical Devices
- Adjustable weights, policy recommendation generator, canvas charts
- Fully accessible, single HTML file — no dependencies

## Data Sources
- EIA-861 Utility Data
- Pennsylvania PUC Outage Reports
- CDC PLACES (disability & health)
- CMS Durable Medical Equipment claims
- American Community Survey (ACS)
- NOAA Climate Hazard Indices
- First Street Foundation
